# Pawfect Name

## Project Description

Pafect Name is a simple Python program that creates a playful pet name by combining a word describing the pet's appearance with the user's favourite food. This project helped me practise working with user input, variables, strings, and text concatenation.

## Features

* Welcomes the user to the pet-name generator
* Collects a word describing the pet's appearance
* Collects the name of the user's favourite food
* Combines both answers to suggest a creative pet name

## Skills and Concepts Practised

* Displaying messages with `print()`
* Collecting user input with `input()`
* Storing information in variables
* Combining strings through concatenation
* Writing clear instructions for users

## How It Works

The program asks the user for an adjective that describes their pet and the name of a favourite food. It combines the two words and displays the result as a possible pet name.

## Example

```text
Welcome to Pawfect Name!
Having a tough time naming your new little buddy at home? Fret no more! Let Pawfect Name give you a paw-some monikerfor your newest companion!
Give one word to describe your pet's appearance. Start the word with uppercase.
Fluffy
Name your favourite dish. It could be a main dish, snack or ingredient. Start the word with lowercase
Muffin

Say hello to... Fluffymuffin!
```

## How to Run the Project

1. Make sure Python is installed on your computer.
2. Download `pet-name-generator.py`.
3. Open the file in a Python-compatible editor.
4. Run the program.
5. Enter the requested words in the terminal.

## Challenge and Solution

One challenge was making sure the two words formed a readable pet name. I addressed this by asking the user to capitalise the first word and enter the second word in lowercase.
