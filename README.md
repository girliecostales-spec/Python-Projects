# Python Projects

This folder contains programs I created while learning and practising Python. Each project allowed me to apply different programming concepts, solve problems, and improve my ability to write clear and functional code.

Every project folder includes:

* A description of the project
* The features of the program

## How to Run a Project

1. Open the folder of the project you want to try.
2. Download or clone the repository.
3. Make sure Python is installed on your computer.
4. Run the project’s `.py` file in a terminal or Python-compatible code editor.
5. Follow the instructions displayed by the program.
